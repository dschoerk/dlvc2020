\section{Classifier}
For this assignment we implement an image classifier to distinguish images of cats and dogs. Image classification refers to the task of determining a class by judging the visual content (pixel values) of an image.

The classifier is a function $f\colon x \to w$ that takes an image $x \in \mathbb{R}^D$ as an input and outputs the respective class scores $w \in \mathbb{R}^T$. The highest class scores determines the result. The difficulty with this approach is to automatically determine the classification function $f$. Lets first further define the classification model. In this assignment a linear classification model without bias vector is used, which is defined by $f(x) = Wx$, where $x$ is the input image and $W$ is a weight matrix. The class scores in $w$ are simply computed by linear combination of $x$ and $W$. For a more intuitive interpretation one can interpret the rows of $W$ as hyperplanes in $\mathbb{R}^D$, which linearly separate the different classes. The values in the weight matrix $W$ are unknown and need to be learned before applying the classifier.

In general, machine learning techniques perform some kind of function approximation in a multidimensional space of a given domain. By adapting the function approximators' parameters in order to minimize a loss function for a given set of samples. One tries to obtain a model that performs well on the provided samples, but more importantly is generally applicable to arbitrary samples in the given domain. 

% Since learning, however, is always subject to a rather limited set of samples compared to the enormous size of the domain (e.g. $256 \times 256 \times 256^3$ for moderate 8-bit RGB images), imbalanced or biased training sets can easily lead to an overfitted model that performs well on the training set, but is not able to generalize on arbitrary samples. 

A common approach is to split samples into three independent sets, namely training, validation and test set. Tuning of model parameters (e.g. weight matrix $W$) is performed on the training set, whereas hyper parameters, like learning rate and momentum, can be optimized on the validation set. Finally, the models performance is validated with the independent training set and should be used only once to determine the models performance on this yet unseen data. 

% Alternatively to the described splitting approach, often cross-validation techniques are applied. In \emph{deep learning}, however, where large models and vast parameter spaces are frequently encountered, computation time is a scarce resources, where extensive cross-validation techniques may become infeasible. 





\section{Hyper Parameter Tuning and Evaluation}

Hyper parameter tuning was conduced with a random search over $300$ iterations in the parameter space induced by the learning rate $[0,1]$, the momentum $[0,1]$ as well as \emph{classical} and \emph{Nesterov} momentum types. Both two dimensional hyper parameter spaces are illustrated in Figure~\ref{fig:test} with a surface approximating the induced non-convex and rugged search landscapes. Model performance during parameter tuning was evaluated with its accuracy on the validation set $\mathcal{D}_V$, whereas the the accuracy on the test set $\mathcal{D}_T$ served as final performance measure. Table~\ref{tab:results} shows the best parameters and the respective accuracies in the validation and test set.

In general, our binary image classifier performs quite poorly and with an accuracy of $\approx 59\%$ is only slightly better than by selecting a class by chance. Reasons for this are manifold, but most importantly due to the fact that the classifier is only linear in nature, thus as described previously can only decide linear separable classification problems. This may be an indicator for this image classification task not being linear separable. Furthermore, the sheer vectorization of the input image may also not be highly advantageous for the classification task, since a lot of structural information, like neighbourhood relationships amongst pixels and channels are lost. Although a network could theoretically \emph{relearn} such relationships, we claim that this would probably require deeper (non-linear) networks, while still not being comparable to more advanced approaches like CNNs. Regarding momentum types and parameters we claim that data acquired in the course of this limited experiment may be insufficient for any reasonable claims, however, parameters for the learning rate seem to be in reasonable range for a moderate convergence towards a (local) optimum. To observe significant differences with respect to the convergence behaviour of momentum types, we claim that these experiments remain insufficient.
